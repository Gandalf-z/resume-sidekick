# 求职随身简历 · Resume Sidekick

一个面向 Chrome / Edge 的本地优先简历资料助手。把常用基础信息、工作经历、项目经历与面试回答整理成可搜索、可复用的资料卡，支持快速复制、多项合并复制、网页填入，以及本地 PDF 简历解析。

> **版本来源说明：** 当前仓库初始提交是根据本机可恢复源码构建的 **V1.2.0 恢复版**，用于建立长期、可追溯的维护基线。它不是此前历史开源交付包的逐字节复原。找到历史原始开源包后，会单独比对并以新的提交补回，不会伪称当前快照就是原版。

## 功能

- 搜索和分类管理基础信息、工作经历、项目经历、AI 项目和面试问答。
- 精简版 / 详细版切换。
- 单个字段快速复制，或勾选多个字段后一次复制。
- 尝试把字段填入当前招聘网页；最终提交仍由用户确认。
- 在本地解析 PDF 简历，预览、编辑并确认识别出的资料后再导入。
- 支持 JSON 备份导入 / 导出。
- 简历资料保存在浏览器本地存储，不需要自建后端或 API Key。

## 安装（开发者模式）

1. 下载本仓库 ZIP 并解压，或克隆仓库。
2. 在 Chrome 打开 chrome://extensions/；Edge 打开 edge://extensions/。
3. 开启「开发者模式」。
4. 选择「加载已解压的扩展程序」。
5. 选择仓库内的 extension/ 文件夹（其中直接包含 manifest.json）。
6. 点击扩展图标打开侧边栏。

> 如果要接续某个既有安装中的本地资料，请先在旧插件中导出 JSON 备份。不要为了升级而先卸载旧插件；未打包扩展的路径变化可能导致扩展 ID 改变。新安装后可通过「导入备份」恢复资料。

## 测试

需要 Node.js。运行以下命令：

    cd extension
    npm test

测试包括本地简历文本解析和匿名演示 PDF 的文本提取。

## 隐私与安全

- 当前源码包不包含个人简历 JSON、Chrome 本地存储数据库或账号凭据。
- 个人简历内容只应保存在用户自己的浏览器存储中；导出的 JSON 可能包含姓名、电话、邮箱和工作经历，请妥善保管。
- PDF 解析在本地完成。填入网页后请人工核对；插件不会替用户点击最终提交。
- 公开仓库中的演示 PDF 应保持匿名，不要把真实简历或备份提交到 Git。
